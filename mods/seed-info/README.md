# Seed Info — Български превод

Превод за Seed Info 1.0.5.

Публикуемият файл е `SeedInfo/i18n/bg.json`. Архивът е предназначен да се разархивира в `Mods`, където добавя само `bg.json` към вече инсталирания оригинален мод.

Този превод е публичен в GitHub репото, но не е публикуван в Nexus. Преди Nexus upload попълнете Nexus Mod ID и file group ID в `release/mods.json`, след което задайте `nexusPublished` на `true`.
