# UI Info Suite 2 Alternative - Български превод

## Описание
Български превод за [UI Info Suite 2 Alternative](https://www.nexusmods.com/stardewvalley/mods/43127).

Пакетът съдържа готови файлове за папката `UIInfoSuite2Alt\\i18n`.

## Съвместимост
- Версия на превода: `0.5.2`
- Синхронизиран с: `UI Info Suite 2 Alternative 2.8.35`

## Промени в 0.5.2
- Добавен е новият низ `ShowBirthdaysForUnmetVillagers`.
- Пакетът вече включва български превод и в `bg.json`, и в `default.json`.

## Инсталация
1. Изтеглете и инсталирайте оригиналния мод:
   [UI Info Suite 2 Alternative](https://www.nexusmods.com/stardewvalley/mods/43127)
2. Отворете папката `Mods\\UIInfoSuite2Alt`.
3. Копирайте съдържанието на `i18n` от този пакет в `Mods\\UIInfoSuite2Alt\\i18n`.
4. Потвърдете замяната на файловете.

## Бележки
- `bg.json` е за игра с активен български превод.
- `default.json` е същият български превод за играчи, които искат да ползват UI Info Suite 2 Alt на български и без основния български мод.

## Статус на публикуването
- Пакетът е подготвен за GitHub release, но Nexus качването е умишлено изключено.
- При бъдещо публикуване в Nexus: създай страница на мода, добави `NEXUS_MOD_ID_UIINFOSUITE2ALT_BG` и `NEXUS_FILE_ID_UIINFOSUITE2ALT_BG`, после включи Nexus публикуването в `release/mods.json`.
